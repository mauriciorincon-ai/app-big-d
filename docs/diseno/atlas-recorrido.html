Todos los pasosAll steps

Desliza de lado para ver las seis capas.Swipe sideways to see all six layers.

Los pasosThe steps

  1. 1
    Nace el registroThe record is born Sistema de admisionesAdmissions system

    Un paciente ficticio ingresa y queda registrado.A fictional patient is admitted and registered.

    Inserción en la tabla de admisiones con marca de tiempo de modificación.Insert into the admissions table with a modification timestamp.

  2. 2
    Se detecta el cambioThe change is detected Captura de cambiosChange capture

    La plataforma nota que hay un registro nuevo.The platform notices there is a new record.

    El lector del registro de transacciones emite el evento de inserción.The transaction-log reader emits the insert event.

  3. 3
    Se guarda tal cualStored as is Zona de datos crudosRaw data zone

    El registro se guarda sin modificar.The record is stored unmodified.

    Anexión a la tabla cruda con versión y metadatos de carga.Append to the raw table with version and load metadata.

  4. 4
    Se limpia y combinaCleaned and combined Motor de transformaciónTransformation engine

    Se corrigen formatos y se une con otros datos del paciente.Formats are corrected and it is joined with the patient's other data.

    Transformación por lotes con reglas de calidad; los registros que fallan se apartan.Batch transformation with quality rules; records that fail are set aside.

  5. 5
    Queda listo para usarseReady to be used Tablas limpias en formato abiertoClean tables in an open format

    El registro limpio queda disponible para tableros y agentes.The clean record is available to dashboards and agents.

    Escritura transaccional en la tabla limpia; el catálogo registra el linaje.Transactional write to the clean table; the catalog records the lineage.

    Aquí el camino se bifurca en paralelo: 6a hacia el tablero y 6b hacia el agente.Here the path forks in parallel: 6a towards the dashboard and 6b towards the agent.

  6. 6a
    Se vuelve indicadorBecomes an indicator Modelo semánticoSemantic model

    Cuenta dentro del indicador de admisiones del día.It counts inside the day's admissions indicator.

    Lectura sin copia por el modelo semántico; aplica la seguridad por filas.Read without copy by the semantic model; row-level security applies.

  7. 7a
    Aparece en el tableroShows on the dashboard Tablero de ocupaciónBed occupancy dashboard

    La dirección ve la ocupación actualizada.Management sees the updated occupancy.

    Consulta a demanda del tablero al modelo semántico.On-request query from the dashboard to the semantic model.

  8. 6b
    Sirve de contexto a un agenteServes as context for an agent Agente de preguntas sobre datosData question agent

    Un agente puede responder cuántos ingresos hubo hoy.An agent can answer how many admissions there were today.

    Consulta a demanda bajo los permisos del catálogo; funcionalidad en vista previa.The agent reads the clean tables under the catalog's permissions.
