Evidencias. Un archivo por entidad; cada evidencia con fuente, fecha, madurez, conflicto de interés, vigencia y verificación. Solo las aprobadas participan del puntaje; la propuesta se ve, pero no cuenta.

Error de carga. Una base incompleta no carga: cada error dice archivo, línea, id, campo y regla. Nada se completa por inferencia y ninguna pantalla del caso se calcula hasta que se corrija.

Instantánea con huella. Cada versión de la base lleva su huella SHA-256 sobre JSON canónico (RFC 8785). El informe cita la instantánea con la que se calculó; cualquiera la puede volver a verificar.
